Local modifications in Frontier V15, 2026-09-27:

1. Retain k23's default 10-turn ready-stock sale lookahead.
2. During day 8, observe only public farm state and require four consecutive
   matches of money, worker positions, unlocked land, and productive tile
   layout before certifying a same-schedule opponent.
3. After certification, and only while k23's existing public-state clone gate
   remains active, use a 12-turn sale lookahead. Restore the default after
   every call so state cannot leak between observations or games.
4. Ignore stochastic weeds in the certification fingerprint. No hidden
   opponent inventory, private state, replay identity, or external data is
   used at runtime.

Frontier V16 public competition replay data
-------------------------------------------
The route schedules added by Frontier V16 were derived from public
Kaggriculture DSM competition replays. Kaggriculture Competition Data
is made available under Apache-2.0 Data Access and Use terms. Exact
episode IDs, submission IDs, seats, seeds and replay SHA-256 hashes
are recorded in the repository artifact manifest. No DSM private
source code is included.

Frontier V17 observable capacity reallocation
-----------------------------------------------
Local Apache-2.0 modification: future livestock purchases, matching
structures and placements are reallocated from days 6-18 only when
one public town-shop demand family is the unique leader.
