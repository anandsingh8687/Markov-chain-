FASTAPI ARCHITECTURE MAP (verified at commit f1d750fd; notes on older checkouts at the end)

1. PACKAGE LAYOUT (fastapi/)
- applications.py: class FastAPI(Starlette). Holds self.router (an APIRouter), exception_handlers, build_middleware_stack, openapi(), setup() (adds /openapi.json, /docs, /redoc routes). Its get/post/add_api_route/include_router/websocket methods just delegate to self.router.
- routing.py: APIRoute, APIWebSocketRoute, APIRouter, get_request_handler, get_websocket_app, serialize_response, run_endpoint_function, request_response, websocket_session, _populate_api_route_state, include machinery (_RouterIncludeContext, _IncludedRouter, _EffectiveRouteContext, RouteContext, iter_route_contexts).
- dependencies/models.py: dataclass Dependant (path_params, query_params, header_params, cookie_params, body_params, dependencies, call, request_param_name, response_param_name, use_cache, scope, cache_key ...).
- dependencies/utils.py: get_dependant, analyze_param, add_param_to_fields, get_flat_dependant, get_typed_signature, solve_dependencies, request_params_to_args, request_body_to_args, get_body_field, _should_embed_body_fields.
- params.py: FieldInfo subclasses Param (Path, Query, Header, Cookie) and Body (Form, File), plus Depends and Security dataclasses. param_functions.py: the public functions Path(), Query(), Header(), Cookie(), Body(), Form(), File(), Depends(), Security() that build those classes (same parameter lists, documented with Annotated[..., Doc(...)]).
- _compat/: __init__.py re-exports; shared.py (lenient_issubclass, field_annotation_is_scalar, is_uploadfile..., annotation_is_pydantic_v1); v2.py (ModelField dataclass wrapping a TypeAdapter with validate/serialize/serialize_json, get_definitions, get_schema_from_model_field, create_body_model, get_missing_field_error, Undefined, RequiredParam).
- openapi/utils.py: get_openapi, get_openapi_path, _get_openapi_operation_parameters, get_openapi_operation_request_body, get_openapi_security_definitions, generate_operation_id, generate_operation_summary, get_fields_from_routes, validation_error_definition. openapi/models.py: pydantic models of the OpenAPI document. openapi/docs.py: get_swagger_ui_html, get_redoc_html, get_swagger_ui_oauth2_redirect_html. openapi/constants.py: REF_PREFIX etc.
- exceptions.py: HTTPException, WebSocketException, FastAPIError(RuntimeError), DependencyScopeError, ValidationException, RequestValidationError, WebSocketRequestValidationError, ResponseValidationError, PydanticV1NotSupportedError, FastAPIDeprecationWarning, EndpointContext.
- exception_handlers.py: http_exception_handler, request_validation_exception_handler (422 with detail=jsonable_encoder(exc.errors())), websocket_request_validation_exception_handler.
- encoders.py: jsonable_encoder, ENCODERS_BY_TYPE, decimal_encoder. utils.py: is_body_allowed_for_status_code, get_path_param_names, create_model_field, generate_unique_id, deep_dict_update, get_value_or_default.
- datastructures.py: UploadFile, DefaultPlaceholder, Default(). security/: base.py SecurityBase, api_key.py, http.py (HTTPBasic, HTTPBearer, HTTPDigest), oauth2.py, open_id_connect_url.py; each scheme is a callable class with async __call__(request) and make_not_authenticated_error.
- sse.py: EventSourceResponse, ServerSentEvent, format_sse_event. middleware/asyncexitstack.py: AsyncExitStackMiddleware. responses.py, requests.py, websockets.py, testclient.py, staticfiles.py, templating.py mostly re-export Starlette.

2. DATA FLOWS
Route creation: app.get(...) -> APIRouter.api_route/get -> APIRouter.add_api_route merges router-level options (prefix, tags, dependencies, responses, callbacks, deprecated, include_in_schema, default_response_class, generate_unique_id_function, strict_content_type) with the route arguments, then route_class(...) -> APIRoute.__init__ -> _populate_api_route_state. That function infers response_model from the return annotation when response_model is Default, builds response_field via create_model_field, computes unique_id, builds route.dependant = get_dependant(...), prepends router dependencies with get_parameterless_sub_dependant, computes _flat_dependant, _embed_body_fields and body_field (get_body_field). Then self.app = request_response(self.get_route_handler()).
Parameter analysis: get_dependant iterates get_typed_signature(call).parameters; analyze_param decides per parameter: Annotated metadata or default value gives FieldInfo or Depends; Request/WebSocket/Response/BackgroundTasks/SecurityScopes are special (add_non_field_param_to_dependency); otherwise path name -> Path, UploadFile -> File, non-scalar -> Body, else Query. Header aliases convert underscores to hyphens. Sub-dependencies recurse through get_dependant. Invalid combinations raise AssertionError with a message.
Request handling: APIRoute.handle -> get_request_handler(...).app(request): reads body (form via request.form(), JSON if content-type is json or +json, strict_content_type), JSON errors become RequestValidationError(type json_invalid); solve_dependencies resolves sub-dependencies (cache via dependency_cache and cache_key, dependency_overrides_provider.dependency_overrides, yield dependencies on AsyncExitStacks in scope keys fastapi_inner_astack / fastapi_function_astack), then request_params_to_args for path/query/header/cookie and request_body_to_args for body. Errors -> RequestValidationError. Otherwise run_endpoint_function (threadpool for sync def) -> serialize_response (response_field.validate then serialize or serialize_json; ResponseValidationError on failure; jsonable_encoder when no field) -> response_class(content, status_code, background). Generator endpoints stream as JSONL or SSE. Body is emptied when is_body_allowed_for_status_code is False. Websockets: APIWebSocketRoute -> get_websocket_app -> solve_dependencies -> WebSocketRequestValidationError.
Option threading: defaults use Default(value) (a DefaultPlaceholder); get_value_or_default(first, *rest) returns the first non-placeholder. include_router at this commit is lazy: it appends an _IncludedRouter(original_router, _RouterIncludeContext) instead of copying routes; _RouterIncludeContext.combine merges nested includes (prefix concat, tags/dependencies/callbacks concatenated, responses dict-merged, deprecated or-ed, include_in_schema and-ed, response class and unique id via get_value_or_default); _EffectiveRouteContext.from_api_route produces the per-include effective route values used for matching, handling and OpenAPI; consumers iterate routes with iter_route_contexts.
OpenAPI: FastAPI.openapi() caches get_openapi(...) keyed on router._get_routes_version(); get_openapi collects fields (get_fields_from_routes), get_definitions, then get_openapi_path per route context builds parameters, requestBody, responses (adds 422 HTTPValidationError when there are params or a body), security, callbacks; the result is jsonable_encoder(OpenAPI(**output), by_alias=True, exclude_none=True).
Errors: FastAPI.__init__ registers default handlers with exception_handlers.setdefault; build_middleware_stack puts ServerErrorMiddleware, user middleware, ExceptionMiddleware, AsyncExitStackMiddleware around self.router.

3. WHERE CHANGES GO
- New route/router option: add to APIRoute.__init__, _populate_api_route_state, _APIRouteLike, APIRouter.__init__/add_api_route/api_route and every verb method (get, put, post, delete, options, head, patch, trace), FastAPI verb methods and add_api_route, and include-level merging (_RouterIncludeContext, _EffectiveRouteContext) if it can be set per router.
- New parameter option: params.py class plus matching param_functions.py function; analysis in analyze_param; OpenAPI in _get_openapi_operation_parameters.
- Validation/error messages: dependencies/utils.py, exceptions.py, exception_handlers.py, _compat/v2.py (_regenerate_error_with_loc, get_missing_field_error).
- Serialization: serialize_response, jsonable_encoder, ModelField.serialize.
- OpenAPI output: openapi/utils.py and openapi/models.py. Security schemes: fastapi/security/.

4. CONVENTIONS
- Internal invariants use assert with a message; user-facing config errors raise FastAPIError; HTTP errors raise HTTPException(status_code, detail, headers).
- Keyword-only args, modern typing (X | None, list[...]), Annotated[..., Doc("...")] documentation on public signatures.
- Tests in tests/, flat files test_*.py; they build a small FastAPI() app, use fastapi.testclient.TestClient(app), assert response.status_code and response.json(), and often compare app.openapi() or client.get("/openapi.json").json() with inline_snapshot snapshot(...). Tutorial code lives in docs_src/<topic>/tutorialNNN_py310.py with tests in tests/test_tutorial/test_<topic>/ importing the module via importlib and a parametrized client fixture; markers needs_py310 etc. live in tests/utils.py.

5. PITFALLS
- Sync def endpoints/dependencies run in a threadpool; async ones are awaited; generators vs async generators differ (is_gen_callable, is_async_gen_callable).
- HTTP and websocket paths are separate (get_request_handler vs get_websocket_app, APIRoute vs APIWebSocketRoute, separate exception handlers).
- Router-level vs app-level vs include_router-level options merge differently; check both add_api_route and the include context code.
- Default() placeholders are truthy/falsy by value; test with isinstance(x, DefaultPlaceholder), not truthiness.
- analyze_param copies FieldInfo before mutating; do not mutate shared FieldInfo/Depends objects.
- OpenAPI schema is cached; mode "validation" vs "serialization" schemas differ (separate_input_output_schemas).
- Older checkouts (around 2025) differ: fastapi/_compat.py is a single module with PYDANTIC_V2 branches (keep v1 and v2 branches in sync), include_router eagerly copies each route by calling self.add_api_route/add_api_websocket_route with merged values, and Python 3.8 syntax (Optional, List) is required.
